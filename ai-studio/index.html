수강생 사용 안내

1. 작품 기록하기

작품 등록에서 제목과 이미지 프롬프트를 입력하고 완성 이미지를 첨부하세요.

2. 내 보관함에서 확인하기

작품과 프롬프트를 현재 기기의 브라우저에 보관하고, 필요한 내용을 복사할 수 있습니다.

3. 문서 자동 분류

DOCX 등 수업 자료를 업로드하면 텍스트를 읽어 키워드 기반 카테고리로 저장합니다. 분류 결과는 수정할 수 있습니다.

4. 백업·내보내기

JSON 백업으로 자료를 보존하고, 선택한 작품만 별도 공유 HTML로 내보내세요. 다른 사용자에게 자동 전송되지는 않습니다.

홈 화면 바로가기: Android Chrome 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'. iPhone Safari 공유 → '홈 화면에 추가'. 개인정보나 학생 얼굴이 담긴 문서는 공개 파일로 배포하지 마세요.
